# Compressor efficiency validation

- Source: [지정 Notion baseline 보고서](https://app.notion.com/p/3eb6947d125d814d9480db29404ebbd3).
- 원본: TMHP-feat-compressor-efficiency-defaults/src/tmhp/compressor_efficiency.py, commit d9fa2f3646df66493f499308723a63e49fbb91d6.
- 출하계수 v2026-09-24를 그대로 사용. tuned n0=.20 / c=.10 / combined penalty를 사용하지 않았다.
- 모든 다섯 모델은 공유 factory/evaluator를 사용한다. ASHP/GSHP 기본 정격속도는 60 rev/s, boiler 계열은 40 rev/s. 동일 PR/rps/rps_rated에서 함수값이 일치한다.
- None은 생성자에서 해당 baseline 함수로 해석한다. float와 callable(PR), callable(PR,rps)를 지원한다. JSON의 효율 상수 입력을 삭제했고 monkey-patch를 사용하지 않았다.
- 각 candidate 속도에서 eta_v/eta_is/eta_em을 평가한다. 질량유량=Vdisp*rho_suction*eta_v*rps; 토출 엔탈피=h_in+dh_is/eta_is; 전력=m_dot*(h_out-h_in)/eta_em. 전기기계 손실은 냉매 열수지 밖에 두며 중복 나누지 않는다.
- 이전 실제 비교군 A는 eta_is=.70, eta_v=.90, eta_em=.80이다. 계획 §14의 “eta_v/em 미적용”은 현재 이전 결과와 다르므로 그대로 표기하지 않았다. 이전 원본 UA1440/640은 보관했다. 사용자 후속 요청에 따라 이번 논문은 UA800/1600 W/K이며, 효율 변화만 비교하기 위해 이전 상수효율 조건도 같은 UA800/1600으로 재계산했다. CSV의 historical 열은 실제 이전 UA1440/640 결과이며 순수 효율 효과로 해석하지 않는다.
- float·1/2인자 callable, 실제 속도 root, 질량유량·전력 수지, 다섯 모델 parity 테스트를 통과했다. 과거 dynamic/kernel/HX goldens는 원래 효율을 명시하여 기존 물리를 검증한다.
- 전체 성공점에서 actual efficiency/model parity, normalized speed, mass flow, 3-power total, gas-work, ground/HX 수지 검증을 수행했다.

## 저부하 판정

- constant, PLR .3/.4/.5: rps=[27.0313, 34.4397, 41.3644], η_v=[0.95979, 0.97045, 0.97696], η_is=[0.64338, 0.63959, 0.63724], η_em=[0.8783, 0.88857, 0.89495]; PR floor 3/3점.
  COP_sys=[9.70472, 9.74113, 9.69342]. 이 범위의 최대값은 PLR 0.4이다.
- optimal, PLR .3/.4/.5: rps=[26.2614, 33.5946, 40.6039], η_v=[0.95833, 0.96947, 0.97635], η_is=[0.64389, 0.63995, 0.63746], η_em=[0.87692, 0.88761, 0.89435]; PR floor 3/3점.
  COP_sys=[9.97427, 9.8843, 9.75945]. 이 범위의 최대값은 PLR 0.3이다.
- 속도는 저부하에서 실제 감소하며 세 효율은 운전점 함수값으로 반영된다. baseline은 η_is=η_oi/η_em으로 유도하므로, 낮은 PR과 속도에서 η_is가 증가할 수도 있다. η_is와 η_em이 독립적인 단조 저하 모델이라고 해석하지 않는다.
- 저부하 COP 상승은 낮아지는 냉매 lift와 baseline 효율 곱의 변화가 함께 결정한다. 결과를 낮추기 위해 tuned penalty를 추가하지 않았다. cycling/on-off 및 실측 장비 보정은 이번 정상상태 모델에 포함되지 않는다.
- 개발 그림: fig_compressor_speed, fig_compressor_efficiencies, fig_compressor_pressure_ratio. 빈 표식은 PR floor에 투영된 점이다. 모두 scientific style과 dartwork-mpl MCP를 사용한다.
