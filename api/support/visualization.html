Compressor maps and calibration figures¶

Three figures, always drawn the same way, for recording a compressor map change or a catalogue calibration (#256):

  • plot_compressor_map() – one efficiency over pressure ratio and speed at fixed evaporating temperatures (−15, 0 and 10 °C by default); row 1 before, row 2 after. Every heat-pump model has it as a method, model.plot_compressor_map(), with the model’s efficiencies as after and the default maps as before.

  • plot_calibration_stages() – COP RMSE and MAPE after each calibration stage, fitted and cross-validated.

  • plot_cop_parity() – model against catalogue COP, before and after, with the error scores.

import dartwork_mpl as dm
from tmhp import AirSourceHeatPumpBoiler

dm.style.use("report")
model = AirSourceHeatPumpBoiler(hp_capacity=9000.0, ref="R290", eta_cmp_isen=my_isen)
fig = model.plot_compressor_map()  # default maps (top) vs this model (bottom)

Fixed-form figures of the compressor efficiency maps and of a calibration’s performance (#256).

Three figures, always drawn the same way so that results recorded in different issues can be compared at a glance:

plot_compressor_map()

One efficiency over (pressure ratio, speed) at a few fixed evaporating temperatures: row 1 before, row 2 after, one column per T_evap. Axis ranges and colour levels are fixed per quantity. Every heat-pump model also has it as a method (CompressorMapPlotMixin), with its own efficiencies as after and the default maps as before.

plot_calibration_stages()

COP error after each calibration stage: RMSE of ln(COP_model / COP_catalogue) on the left, MAPE on the right; a line for the fit to all points and markers for the cross-validated value (filled = adopted).

plot_cop_parity()

Model against catalogue COP, before on the left and after on the right, on the same axes, with the error scores in the panel titles.

Each function returns a matplotlib.figure.Figure and sets no global style; apply one (for instance dartwork_mpl.style.use("report")) before calling. Colours: grey = before (default maps), violet = after (calibrated), orange = the data range of the default maps, blue = efficiency magnitude.

tmhp.compressor_plots.plot_compressor_map(before, after, *, T_evap_C=(-15.0, 0.0, 10.0), quantity='eta_ov', points=None, labels=('Default maps', 'Calibrated'), pr_range=(1.4, 13.0), rps_range=(15.0, 120.0), title=None, resolution=(140, 120))[source]¶

Efficiency map before (row 1) and after (row 2), one column per evaporating temperature.

before and after are each a mapping of the three efficiencies (eta_cmp_isen, eta_cmp_vol, eta_cmp), a heat-pump model (its attributes of those names), or None for the default maps. quantity is a key of MAP_QUANTITIES; its colour levels are fixed, values beyond them take the end colours. Axes: pressure ratio r_p (log, pr_range) and speed N [rev/s] (rps_range), shared by all panels.

Drawn on every panel: the efficiency (filled contours, labelled lines), the data range of the default maps at that T_evap (orange), and the grid peak (diamond; value and place in the panel title). points (an OperatingPoints or model result rows) are drawn on the column whose T_evap is nearest to each point’s. resolution is the grid size (pressure ratio, speed).

Returns the figure (2 x len(T_evap_C) map axes and one colour bar). Raises ValueError for an unknown quantity or no temperatures, and TypeError for an efficiency source without the three efficiencies.

tmhp.compressor_plots.plot_cop_parity(cop_catalogue, cop_before, cop_after, *, mode=None, labels=('Default maps', 'Calibrated'), band=0.1, title=None)[source]¶

Model against catalogue COP: before (left, grey) and after (right, violet) on the same square axes.

Equal-length arrays; a non-finite or non-positive model value is a point the model did not solve, left out of the plot, the axis range and the scores alike and counted in the title. Each panel title gives MAPE, bias and RMSE (cop_errors()). Lines: y = x and ±band (dashed). mode per point: "heating" circles, "cooling" squares, anything else triangles. Raises ValueError as cop_errors() or when mode has another length.
