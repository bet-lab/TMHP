## 재현 및 판정

```sh
uv run python -m validation.default_inputs.source_supplement.compare
uv run --with dartwork-mpl==0.7.0 python -m validation.default_inputs.source_supplement.plot
```

배제체적 그림의 가로축은 각 행의 냉방 용량을 `흡입 밀도 × 냉동효과 × 시험 회전수 또는 주파수`로
나눈 값입니다. 이 좌표에서 배제체적 추정은 원점을 지나는 직선입니다. 고정속 공급 전원 주파수와
인버터 시험 설정은 문서가 밝힌 기준이며 직접 측정한 축 회전수가 아닙니다. 다른 압축기 기준끼리 합치지 않았습니다.
풍량 회귀는 정격 용량을 kW로, 풍량을 m³/s로 환산해 기존 제품군 가중과 모형 선택 규칙을 재사용합니다.

기존 행 평가는 두 회차 모두 동일한 제품군 또는 제조사 보류 행에 한정합니다. 추가 행 평가는
해당 제조사 전체를 양쪽 학습에서 뺍니다. 예를 들어 Gree가 해당 층의 유일한 신규 제조사이면
Gree를 통째로 뺀 전후 학습 집합이 같아 추가 행 보류 오차도 같습니다. 정속 LG 제외 행은
기존 배포 회귀를 재현할 때만 썼으며 공통 평가점에는 넣지 않았습니다. LG 행을 유지하고
GMCC만 추가한 계수도 `comparison.json`에 별도로 남겼습니다.

관측 및 회귀식은 후보 자료입니다. 완제품 카탈로그 검증과 EnergyPlus 등 외부 소비자 검증을
수행한 결과는 포함하지 않습니다. 이번 비교는 압축기 단품에서 완제품 정격으로 전이할 때의
오차를 입증하지 않습니다. 출고 계수 재평가는 #86의 완제품 검증을 거쳐야 합니다.

공기–물 실외 난방 층은 제조사 6곳에서 7곳으로 늘었습니다. 확대 데이터 전체의 제품군 보류
MAPE는 28.29%, 제조사 보류 MAPE는 28.38%로, 기존 기준 20%를 모두 넘었습니다.
Bosch 전체를 보류한 경우의 MAPE는 97.36%입니다. 오차가 크다는 이유만으로 원자료를
삭제하면 제조사 간 차이를 가리므로 원문 근거와 함께 기록했습니다.
학습하지 않은 Panasonic 9대의 MAPE는 14.14%에서 15.51%로, 편향은 −8.00%에서
−10.07%로 바뀌었습니다. 최대 표기 행만 훈련한 식에 대한 전체 행 식의 비는 기존
0.992–1.079에서 1.145–1.307로 바뀌어 0.90–1.10 기준을 벗어났습니다.

검증한 풍량 원문은 17건입니다. Git에는 회귀에 사용한 수치와 출처만 있으며 신규 NAS 적재
후보 15건의 정확한 파일 크기와 SHA-256은 [풍량 출처 원장](airflow/sources.json)에 있습니다.
그중 Mini Console 18의 사양서는 불일치 확인용입니다.
