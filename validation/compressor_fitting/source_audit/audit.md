# Ossorio 효율맵 원천 검증

- 확인일: 2026-11-01.
- 결론: `f_loss = k0 + k1*PR + k2*PR/(N/70) + k3/P_el` 해석은 **저자 학위논문의 식과 R290 실측 134점으로 뒷받침된다**. 저널 Eq.22의 인쇄식만 그대로 구현하지 않는다.
- 데이터 유형: 공개 저자 학위논문의 반올림된 실측 표를 전수 추출했다. 그림에서 점을 역추정하거나 합성점을 실측으로 바꾸지 않았다.
- 검증 결과는 `audit_results.json`, 추출 실측은 `ossorio_thesis_r290_134.csv`, 점별 계산은 `ossorio_thesis_r290_134_audit.csv`에 있다.

## 1. 원문 식의 충돌과 해소 근거

2024 저널 p11 Eq.19는 `eta_em = mdot*(h2-h1)/P_el`로 정의한다. 같은 페이지의 인쇄 Eq.22는 `eta_em = k0 + k1*PR + k2*PR/f_rat + k3/P_el`이다. 그러나 p14 Table 5의 R290 계수는 `(0.103, -0.00390, 0.00800, -14.8)`이고, 인접 설명은 k0를 약 10%의 기본 손실률이라고 해석한다. 그대로 대입하면 eta_em이 약 0.1이 되어 본문 p11의 약 0.85–0.9와 맞지 않는다.

저자 Rubén Ossorio의 [UPV 학위논문](https://riunet.upv.es/bitstreams/6612b905-7a7a-436d-b73c-ac1bc903c27a/download), 인쇄 p88 / PDF p116, Eq.3.22는 아래처럼 **1에서 네 항을 빼는 식**을 명시한다.

```text
eta_em = 1 - k0 - k1*PR - k2*PR/f_rat - k3/P_el
f_loss = 1 - eta_em
       = k0 + k1*PR + k2*PR/f_rat + k3/P_el
f_rat = N / N_nom, N_nom = 70 rev/s
```

학위논문 Table 3.5(인쇄 p91 / PDF p119)를 렌더링해 저널 Table 5와 R290 계수가 같은 것을 육안 대조했다. 저널의 정식 erratum을 확인했다는 뜻은 아니다. 이번 구현은 저자 학위논문에 표시된 식을 채택하고, 저널 인쇄식과의 차이를 출처 메타데이터에 남긴다. 개별 회귀계수(특히 음수 k3)를 각각 독립적인 물리 손실이라고 해석하지 않는다.

## 2. 확보한 원자료와 실제 검증

학위논문 Appendix 1, PDF p243의 사양표 및 PDF p244–252의 표에서 **134행 전체**를 추출했다. 각 행에 PDF 페이지와 페이지 내 행 번호를 남겼다. 열은 Te, Tc, N, Tsuc, Tdis, 질량유량, 압축기 전력, 압축기+인버터 전력, eta_v, eta_is, eta_comp이다. 30/50/70/90/110 rev/s의 다섯 속도군이며 행 제외는 없다.

| 검증량 | 134점 결과 | 비교 기준 |
|---|---:|---|
| 저널 Eq.22 우변을 eta_em으로 그대로 사용한 RMSE | 0.753642 | 저자 표의 eta_comp / eta_is |
| 학위논문 Eq.3.22의 eta_em RMSE | 0.011634 | 저자 표의 eta_comp / eta_is |
| 학위논문 Eq.3.22의 eta_em RMSE | 0.011469 | CoolProp로 계산한 mdot*(h2-h1)/P_el |
| 토출온도 RMSE | 0.744708 K | 측정 질량유량·총전력을 조건으로 Eq.3.22와 상태방정식 적용 |
| Eq.10 질량유량 RMSE | 0.222220 g/s | 측정 질량유량 |
| Eq.17 총전력 RMSE | 94.887482 W | 측정 압축기+인버터 전력 |

저널 Table 3은 0.22 g/s, Table 4는 90.77 W, Fig.16은 0.741 °C를 보고한다. 위 값은 해당 규모와 부합하지만 **저널 수치의 완전 동일 재현은 아니다**. 저널은 133점, 학위논문 표는 134점이고 제외된 한 점은 식별하지 못했다. 또한 원문의 REFPROP 10.0 대신 CoolProp 7.2.0 HEOS를 사용했으며 인쇄 표의 반올림 오차가 있다. 저자 표의 eta_comp를 같은 총전력·HEOS로 재계산한 차이의 RMSE는 0.002205이다.

이 134점은 원 논문 상관식의 개발 데이터에 해당하므로 독립 검증 자료로 부르지 않는다. 토출온도 검증은 측정 질량유량과 전력을 입력한 조건부 검증이며, 전체 히트펌프나 카탈로그 COP의 검증 결과가 아니다.

기존 `prep_points.py`의 R454C 점검은 별도 근거다. CoolProp PR이 존재하는 66행을 제외 없이 사용하고 저자 제공 `eta_comp/eta_is`와 비교하면, 저널 인쇄 해석 RMSE는 0.664359, 보수식 해석은 0.086343이다(Table 5의 0.09와 같은 규모). 기존 메타데이터의 상관계수 -0.02는 flagged 행을 제외하고 HEOS로 재계산한 손실과 비교한 59점 결과였다. 그 값만으로 식의 보수 해석을 부정할 수 없다. R454C는 혼합냉매 포화상태·물성 차이와 누락 PR이 있어 최종 근거는 더 직접적인 R290 134점 검증으로 삼았다.

## 4. PR–N 맵을 얻는 경로와 한계

원식은 PR과 N만의 함수가 아니다. Eq.10은 Pe/Pc/N으로 질량유량을, Eq.17은 보정된 압력비 `(Pc-k2)/(Pe-k3)`와 N으로 비소비전력을, Eq.3.22는 PR/N/전력으로 손실률을 예측한다. 상태 물성으로 다음처럼 변환한다.

```text
eta_v  = mdot / (rho_suction * displacement * N)
eta_ov = mdot * (h2s - h1) / P_el
f_loss = 1 - eta_em
```

현재 발표 후보의 567점은 Te −10…15 °C(5 K 간격), Tc 20…70 °C(5 K 간격), N 30…110 rev/s(10 간격), Tc−Te≥15 K의 격자에서 원 상관식을 평가한 **합성점**이다. R290, SH 10 K, Vdisp 46 cm³/rev를 사용한다. 이를 PR–N 다항식으로 재회귀하면 그것은 **별도 대리모델**이다. 원식 오차와 대리모델 오차를 구별하고 격자·회귀식·계수·물성 버전·영역을 기록한다. 134개 실측값을 그 567개 합성점과 혼동하지 않는다.

λ 보정은 이 대리모델의 크기를 바꾸는 것이며, R290 스크롤 원천을 다른 냉매·기종에 사용하는 경우 형상 전이 가정이 남는다. 원 논문이 다른 기종에 같은 계수를 검증한 것처럼 표현하지 않는다.
