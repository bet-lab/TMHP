Minimal input¶

TMHP is meant to run from a nameplate, not from a component datasheet. For every released family three statements describe a machine:

  1. which family — the class says what the heat comes from and where it goes (and, for a ground loop, that it is filled with antifreeze);

  2. the capacity — hp_capacity [W], the nameplate duty at the family’s rating point;

  3. the refrigerant — ref, a CoolProp fluid name.

Everything else has a default, and the defaults that describe the size of the machine follow the capacity, so a 3 kW and a 30 kW unit of one family are the same machine at two scales. This page says what each family needs from you, what it fills in, and where each rule comes from.

The rating points are those of Compressor reference state: at construction the compressor’s rated speed is solved so that the machine delivers exactly hp_capacity there, whatever the refrigerant.

from tmhp import (
    AirSourceHeatPump,
    AirSourceHeatPumpBoiler,
    GroundSourceHeatPump,
    GroundSourceHeatPumpBoiler,
    WaterSourceHeatPumpBoiler,
)

# Space conditioning: the load is signed (negative = heating).
ashp = AirSourceHeatPump(hp_capacity=5_000, ref="R32")
a2a = ashp.analyze_steady(Q_r_iu=-5_000, T0=7.0, T_a_room=20.0)

gshp = GroundSourceHeatPump(hp_capacity=5_000, ref="R32")
g2a = gshp.analyze_steady(Q_r_iu=-5_000, T0=0.0, T_a_room=20.0)

# Water heating: the load is the heat the tank receives.
ashpb = AirSourceHeatPumpBoiler(hp_capacity=9_000, ref="R290")
a2w = ashpb.analyze_steady(T_tank_w=50.0, T0=7.0, Q_ref_tank=9_000)

gshpb = GroundSourceHeatPumpBoiler(hp_capacity=9_000, ref="R290")
g2w = gshpb.analyze_steady(T_tank_w=50.0, T_source=10.0, Q_ref_tank=9_000)

wshpb = WaterSourceHeatPumpBoiler(hp_capacity=9_000, ref="R290")
w2w = wshpb.analyze_steady(T_tank_w=50.0, T_source=10.0, Q_ref_tank=9_000)

for name, row in [("ASHP", a2a), ("GSHP", g2a), ("ASHPB", a2w), ("GSHPB", g2w), ("WSHPB", w2w)]:
    print(f"{name:6s} {row['failure_reason']:5s} COP {row['cop_sys [-]']:.2f}")

Each call returns a running point (failure_reason == "none") with a system COP of 4.74, 4.86, 3.44, 3.66 and 3.72 respectively. The keys of the result are listed in Result keys. A time series needs the same quantities as schedules; see Your first dynamic simulation.

The size that the rules give for a machine can be checked in one line:

from tmhp import GroundSourceHeatPump

gshp = GroundSourceHeatPump(hp_capacity=30_000)

print(gshp.N_1, gshp.N_2, gshp.H_b)   # 3 2 100.0  -> six 100 m boreholes
print(gshp.ground_flow_ref_lpm)       # 115.3 L/min of 25 % ethylene glycol
print(gshp.E_pmp)                     # 640 W
print(gshp.UA_ground_rated)           # 5400 W/K

The constructor warns (UserWarning) when a size you give contradicts the rest — a borefield above 80 W/m, a loop flow that is laminar in the U-tubes, a tank set point the refrigerant cannot reach — instead of solving it silently.

Solved for the fluid at the rating point, so the nameplate capacity is kept when the refrigerant is swapped. A fluid of low volumetric capacity (R134a, R1234yf, R600a) then runs fast and may need a larger V_cmp_ref

The default refrigerants are chosen so the default machine runs inside these limits: R32 for the space-conditioning families, R134a for ASHPB (60–65 °C tank) and R290 for GSHPB and WSHPB (55–65 °C tank).

What is on by default¶

These defaults describe how a real unit behaves at the edges of its range. Each can be switched off to see the bare cycle.

Behaviour

Default

Switch

Compressor envelope

A point outside it is not returned as running: pressure ratio above 11, discharge above T_dis_max (after suction control down to quality 0.9), condensing above T_cond_max, isentropic fit below 0.30. A request that a smaller duty meets runs at that duty

PR_cycle_max, T_dis_max=None, x_suction_min, T_cond_max=None (Reference points and operating limits)

On/off operation below the minimum speed

analyze_steady returns the mean of on/off cycling with the EN 14825 degradation: Cd 0.25 for the units delivering to air (ASHP, GSHP), Cc 0.9 for the boilers

Cd_cycling (None: continuous minimum-speed point) (Air-source heat pump (ASHP — space conditioning), Ground-source heat pump boiler (GSHPB))

Frost and defrost

ASHP heating and ASHPB below 5 °C outdoor carry the EnergyPlus frost adjustment at 84 % relative humidity

defrost=None; RH_out per call, RH_out_schedule in a dynamic run; DefrostModel(load_weighted=False) for the same correction at every load (Air-source heat pump (ASHP — space conditioning), Air-source heat pump boiler (ASHPB))

Dynamic borehole

GSHP and GSHPB resolve the heat capacity of fluid, pipe and grout and the fluid transit

borehole_dynamics=False (Ground response)

Source-loop liquid and its freezing limit

GSHP and GSHPB run on 25 % ethylene glycol ("MEG-25%"), WSHPB on water. The loop liquid is never colder than its freezing point plus 3 K (−8.0 °C for the glycol, 3 °C for water): a duty that would chill it further is reduced, and when none fits the unit is off with failure_reason == "source_fluid_freezing"

source_fluid ("water", "MPG-30%", …) (Ground-loop liquid and its freezing limit)

When you know more¶

Any default can be replaced one at a time: a measured UA, a catalogue airflow, a tested Cd_cycling, a compressor map as eta_cmp_isen. The validation harness does exactly that with what manufacturers publish (Validation), and Adding a catalogue shows the pattern. What the models leave out altogether is listed in Scope and limits.
