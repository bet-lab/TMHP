# TMHP 자료 아카이브와 통합 조회 구조 제안 · 2026-10-27

상태: 사용자 검토용 제안. 기존 dataset ID·원자료를 합치거나 옮기지 않았고, 공유 DB·스키마·운영 화면은 변경하지 않았다.

## 권장 구조

원본 보존 단위는 **제조사/저자 × 제품군/자료군 × 배포판**이고, 연구용 조회 단위는 **기기/조합 × 조건 × 물리량 × 출처/검수 상태**로 한다. PDF 한 개마다 독립 DB를 운영하지 않는다. 여러 모델을 담은 같은 제품군의 Submittal·기술문서·성능표는 문서별 판을 보존하는 묶음으로 둘 수 있다. 서로 다른 제조사·50/60Hz·개정판을 무조건 한 원본 폴더로 합치지 않는다.

현재 dataset-catalog는 이미 `_warehouse/catalog.duckdb` 하나에서 여러 `ds_<id>` 스키마/Parquet을 조회한다. 출처별 폴더는 출처·판·해시의 경계를 보존하기 위한 것이며, 별도 DB 서버가 아니다. 같은 열 명세를 갖춘 정리표를 `UNION ALL BY NAME`으로 연결하면 제조사/문서와 관계없이 함께 검색할 수 있다. 이 구조는 저장소의 `pdf-extraction.md`, `pdf-table-extract`, `_tools/guides/pdf-table-data.md`와 맞는다.

## 층과 책임

| 층 | 보관·조회 단위 | 역할 |
|---|---|---|
| 원본 | 출처·판별 PDF/XLSX/HTML, 파일 SHA·권리·취득 경로 | 원문 보존과 재현. 문서가 무엇인지 개요·변수·조건·잠재 활용을 설명 |
| 출처별 검수 표 | 원문 값 하나 + 모델·조합·조건 + 쪽/표/셀·음영/각주 | 인쇄값과 검수 근거를 보존. 교차 추출 미완료 값은 정본으로 승격하지 않음 |
| 공통 조회 | 기기·조합·조건·변수명 규약을 맞춘 Parquet/DuckDB 뷰 | D/E/A/V에 필요한 여러 출처를 한 번에 찾기. 원본 중복 저장 불필요 |
| TMHP 연구 선택 | 특정 모델 버전의 목적별 채택·보류와 이유 | 아카이브의 객관적 정보와 연구 가정/제외 결정을 분리 |

## 공통 표 제안

- `device_models`: 제조사·원문 모델명·시장·전원·변형·냉매·압축기 수/형식·제어. 모델명만으로 동일 설계·독립 장치 수를 결정하지 않는다.
- `combinations`: 정확한 실내기/실외기·수배관 모듈 조합과 회로·배관 조건. 동일 시험표가 여러 외관 모델에 적용된다고 시험점 수를 곱하지 않는다.
- `conditions`: 냉방/난방, 공기 DB/WB 각각, 수측 입출구·유량, 팬 단계·ESP, 부하/정격/최대 정의, 전원 Hz와 물리 rps, 시험 표준·판, 전력·분사·제상 경계.
- `catalog_values`: 기기/조합·조건 키, 물리량, 원문 값/단위, 명시적 환산값/단위, 독립 측정/제조사 선언/제조사 계산/저자 계산 구분.
- 출처·검수 열: dataset ID, 파일 SHA, PDF 페이지와 인쇄 쪽, 표 ID·셀 좌표, 각주·음영 의미, 추출 방식·대조 수준·원문 충돌 여부.
- 용도별 뷰: `compressor_displacement_candidates`, `indoor_airflow_max_candidates`, `outdoor_airflow_max_candidates`, `heatpump_performance_candidates`, `compressor_efficiency_candidates`처럼 같은 원본 표를 필터링한다. 이는 제안한 뷰 이름이며 공유 DB에 생성하지 않았다.

## D/E/A/V 검수 기준

| 용도 | 필요한 확인 | 보류·분리할 사례 |
|---|---|---|
| D 배제체적 | 기하 배제체적·대응 용량의 정의, 냉매·조건·물리 속도·모델 계보 | cm³/rev와 m³/h 혼동, 전원 Hz/코드명60을 rps로 간주, 평가속도 미확인 |
| E 효율/손실 | 압축기 독립 운전점, 유량·흡입/토출 상태·회전수·전력 경계 | 저자 계수/예측을 원시험으로 간주, 인버터 효율을 압축기 효율로 대체 |
| A 최대풍량 | 정확한 조합과 측별 명시적 최대, 냉방/난방·팬모드·ESP·dry/wet | High/정격을 최대로 승격, 실외 풍량을 실내에 사용, 냉동창고 코일을 DX 완제품과 무조건 결합 |
| V Q/P/COP | DB/WB·수온·유량·부하·제상/분사·전력·회로/압축기 수 | 최대출력을 정격/고정속도와 혼합, 펌프 포함 P를 압축기 P와 직접 비교, Q/COP 계산 P를 원문 P로 등록 |

모든 조건은 `확인됨/불일치/미확인`을 구분한다. 미기재는 false가 아니다. 공식 제조사 자료라는 사실은 출처 신뢰도를 뒷받침하지만 모든 격자가 독립 실측이거나 TMHP에 직접 적합하다는 보증은 아니다.

## 실제 새 원문 검토에서 확인한 사례

1. **GREE Sapphire R32:** Submittal 4개는 실내 Min–Max 풍량을 명시한다. 서비스 문서에는 실외 풍량도 있지만 최대 표기가 없어 실외 최대 후보는 보류한다. 확장 성능표는 MAX OUTPUT, Submittal과 문서 날짜도 다르다. 조합·조건별로 연결하고 6개 PDF를 6개 독립 실험 데이터셋으로 세지 않는다.
2. **GMCC Rotary/Scroll 2026:** 모델별 배제체적·냉동능력·입력전력·COP와 개발중/EVI 표기를 제공한다. 시험조건 그림과 코드명의 물리속도 의미를 검수해야 한다. Scroll p5의 중첩 텍스트를 그대로 정본으로 쓰지 않는다.
3. **Mitsubishi PUZ-WZ Vol1:** WZ80은 인버터+고정속 압축기 2개다. 회색 성능 셀은 제상을 포함하고, 정격 P에 EN14511 펌프 입력이 포함된다. p11/A-7의 A35/W18 전력0.35kW와 p73/B-7의1.31/1.53/1.79kW가 충돌한다. 원문 값을 자동 수정하지 않고 해당 비교를 보류한다.
4. **Ossorio 2023:** 논문과 공개 부록3개 확보와 압축기 원시 시험표 확보는 다르다. mmc1은 계수/수식/적합오차, mmc2는 인버터185행, mmc3은 인버터 계수다. 공개 묶음에서 압축기 A/B의 상세 원시표를 찾지 못했다. 논문의 인버터 B/C 시험 수와 XLSX 라벨, 일부 역률 값도 충돌하므로 자동 교체·삭제하지 않는다.

## 화면과 완료 기준

출처 상세에는 자료 개요, 관측 단위, 제공 변수/단위, 입력·조건과 제공량, 잠재 연구 질문, 표·쪽 근거와 제한을 채운다. 전체 수치표 추출이 끝나지 않아도 확인한 내용을 설명한다. 반대로 설명이 충실하다는 이유로 수치표 검수가 끝났다고 표시하지 않는다.

기존 출처 탐색은 유지하고, 용도·기종·냉매·용량 기준·검수 수준으로 함께 검색하는 연구용 진입점을 더하는 것이 좋다. 원본 확보, 내용 설명, 수치 추출, 조건 검수, 연구 채택, 운영 게시의 상태를 각각 표시한다. 기존37개 빈 템플릿은 이 내용 기준으로 보완해야 하며 아직 전체 보완 완료로 간주하지 않는다.

새 PDF 형식은 1–2표의 추출 명세·시각 대조를 먼저 검토한 뒤 전체 추출한다. 모델 회귀·새 효율/COP 계산과 운영 배포는 이번 원문 취득·설계 제안과 구분한다.
